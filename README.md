
# Practical No. 06: Retrieval-Augmented Generation (RAG) using Pre-trained LLM

## Aim
To build a Retrieval-Augmented Generation (RAG) application for answering questions from a domain-specific document collection using a pre-trained Large Language Model (LLM).

## Project Description
This project implements a Retrieval-Augmented Generation (RAG) based question-answering system. It retrieves relevant information from uploaded documents and uses a pre-trained LLM to generate context-aware answers.

The project also compares the responses generated using RAG with those generated by an LLM without retrieval.

## Technologies Used
- Python
- Google Colab
- Hugging Face Transformers
- Sentence Transformers
- FLAN-T5 (Pre-trained LLM)
- NumPy
- PyPDF

## Implementation Steps
1. Install the required libraries.
2. Upload domain-specific documents.
3. Extract text from uploaded documents.
4. Split documents into smaller chunks.
5. Generate embeddings using Sentence Transformers.
6. Load the pre-trained FLAN-T5 model.
7. Retrieve relevant chunks using semantic similarity.
8. Generate answers using the RAG approach.
9. Generate answers using the LLM without retrieval.
10. Compare both approaches.

## Dataset
**Document:** NFA 10.pdf

The document contains topics related to:
- Non-Deterministic Finite Automata (NFA)
- Acceptance of strings by NFA
- Construction of NFA
- Conversion of NFA to DFA
- Subset Construction
- Epsilon-NFA (ε-NFA)

## Working of RAG
1. The user uploads a domain-specific document.
2. The document text is extracted and divided into chunks.
3. Embeddings are generated for each chunk.
4. When a question is asked, relevant chunks are retrieved using cosine similarity.
5. The retrieved context is passed to the pre-trained LLM.
6. The LLM generates an answer based on the retrieved information.

## Comparison: RAG vs LLM Without Retrieval

| RAG | LLM Without Retrieval |
|---|---|
| Uses retrieved document information | Uses pre-trained knowledge |
| Provides document-based context | Does not use uploaded document context |
| Better suited for domain-specific questions when retrieval is relevant | May provide general answers |
| Depends on retrieval quality | Depends on pre-trained knowledge |

## Result
The RAG application was implemented successfully using a pre-trained LLM. It retrieves relevant information from uploaded documents and generates answers. The responses are compared with those generated by the LLM without retrieval.

## Conclusion
Retrieval-Augmented Generation combines information retrieval with text generation. It helps generate more relevant and context-aware answers from domain-specific documents compared to using an LLM without retrieval.
